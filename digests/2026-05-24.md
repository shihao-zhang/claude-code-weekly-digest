## 产品更新 (Product Updates)

- **[v2.1.144 - /resume 后台会话支持 - 2026-05-19]** 新增 `/resume` 命令，支持直接恢复已分离的后台会话，无需手动从 Agent View 列表中选取，进一步打通前台与后台的任务切换流程。([GitHub Release v2.1.144](https://github.com/anthropics/claude-code/releases/tag/v2.1.144))

- **[v2.1.145 - claude agents --json & 插件预览 - 2026-05-19]** 两项面向开发者的效率功能同步上线：
  - **`claude agents --json`**：以 JSON 格式输出当前所有活跃会话列表，专为脚本自动化设计，可对接 tmux-resurrect、状态栏组件、自定义会话选择器等工具链。
  - **`/plugin` 发现页增强**：Browse/Discover 面板在安装前新增插件预览窗格，可直接查看技能列表、MCP 服务器描述及权限清单，降低"盲装"风险。
  ([GitHub Release v2.1.145](https://github.com/anthropics/claude-code/releases/tag/v2.1.145))

- **[v2.1.146 - /simplify 重命名为 /code-review - 2026-05-21]** 原 `/simplify` 命令正式更名为 `/code-review`，语义更准确，功能也随之增强：
  - 支持可选努力等级参数，如 `/code-review high`（高覆盖，可能包含不确定发现）、`/code-review medium`（默认）、`/code-review low`（仅高置信度 Bug）
  - 新增 `--comment` 标志，可将发现直接以内联评论形式推送至 GitHub PR，无需离开终端
  - 旧的 `/simplify` 命令在过渡期内保留别名，后续版本将移除
  ([GitHub Release v2.1.146](https://github.com/anthropics/claude-code/releases/tag/v2.1.146), [Medium 实测文章](https://medium.com/@joe.njenga/how-claude-code-replaced-my-code-review-workflow-and-i-cant-go-back-9abf7b4a30bf))

- **[v2.1.147 - 固定后台会话（Pinned Sessions）- 2026-05-21]** Agent View 新增会话固定能力：
  - 在 `claude agents` 界面中按 **Ctrl+T** 可将任意会话固定至列表顶部
  - 固定会话在空闲时保持进程存活（非固定会话在内存压力下可被回收）
  - Claude Code 自动更新时，固定会话将在原位重启以应用最新版本，最大程度减少任务中断
  - **注意**：v2.1.147 引入了一个回归 Bug（Bash 工具对所有命令返回退出码 127），已在 v2.1.148 中修复。
  ([GitHub Release v2.1.147](https://github.com/anthropics/claude-code/releases/tag/v2.1.147), [Agent View 文档](https://code.claude.com/docs/en/agent-view))

- **[v2.1.148 - 紧急热修复 - 2026-05-22]** 修复 v2.1.147 引入的关键回归：Bash 工具对所有命令一律返回退出码 127（命令未找到），导致几乎所有需要执行 Shell 命令的工作流中断。已在本版本快速修复，建议跳过 v2.1.147 直接升级至 v2.1.148 或更高版本。([GitHub Release v2.1.148](https://github.com/anthropics/claude-code/releases/tag/v2.1.148))

- **[v2.1.149 - /usage 成本分类 & Markdown 渲染改进 - 2026-05-22]** 本周功能最丰富的版本：
  - **`/usage` 分类成本明细**：使用量面板新增按类别拆分的限额消耗展示，可分别查看 Skills、Subagents、Plugins 及各 MCP 服务器的 Token 占用，帮助识别高成本来源
  - **`/diff` 键盘可滚动**：Diff 详情视图现在支持键盘导航（方向键、j/k、PgUp/PgDn、Space、Home/End），彻底告别只能鼠标滚动的时代
  - **GFM 任务清单渲染**：Markdown 输出现在正确渲染 `- [ ] 待办` / `- [x] 已完成` 样式的任务复选框，而不再显示为普通项目符号
  - **企业新配置**：新增 `allowAllClaudeAiMcps` 托管设置项，允许在 `managed-mcp.json` 之外加载 claude.ai 云端 MCP 连接器

  ([GitHub Release v2.1.149](https://github.com/anthropics/claude-code/releases/tag/v2.1.149), [claudeupdates.dev](https://www.claudeupdates.dev/version/2.1.149))

## 实用技巧 (Tips & Tricks)

- **`/code-review` 三档努力等级按需选用**：日常快速检查用 `/code-review low`（仅高置信度 Bug，速度最快）；PR 提交前用默认的 `/code-review`；安全敏感或架构重构时用 `/code-review high`。结合 `--comment` 标志可直接把发现推送为 GitHub inline 评论，无需复制粘贴。([Claude Code Docs](https://code.claude.com/docs/en/changelog))

- **`claude agents --json` 接入状态栏与自动化**：将 `claude agents --json` 嵌入 tmux 状态栏脚本或 shell 函数，可实时展示运行中会话数量；也可与 `jq` 搭配筛选"等待输入"会话并触发系统通知，无需一直盯着 Agent View。([GitHub Release v2.1.145](https://github.com/anthropics/claude-code/releases/tag/v2.1.145))

- **Ctrl+T 固定关键后台会话**：对于跑时间长、不希望被内存回收的后台任务（如大型重构、测试全量覆盖），在 `claude agents` 中按 Ctrl+T 固定该行。固定后即使 Claude Code 自动更新，该会话也会原位重启，不会丢失任务进度。([GitHub Release v2.1.147](https://github.com/anthropics/claude-code/releases/tag/v2.1.147))

- **`/usage` 定位成本黑洞**：v2.1.149 起 `/usage` 可按 Skills / Subagents / Plugins / 单个 MCP 服务器分别显示 Token 占用。若发现某个 MCP 服务器消耗异常高，考虑移除冗余工具或启用 Tool Search 按需加载（可节省约 85% 的 MCP 上下文开销）。([GitHub Release v2.1.149](https://github.com/anthropics/claude-code/releases/tag/v2.1.149))

- **安装前用 `/plugin` 预览再决策**：v2.1.145 起 `/plugin` Browse 面板支持在安装前查看插件详情（技能列表、MCP 工具、权限清单）。建议先预览权限要求，避免安装后才发现插件申请了超预期的文件系统或网络访问权。([GitHub Release v2.1.145](https://github.com/anthropics/claude-code/releases/tag/v2.1.145))
