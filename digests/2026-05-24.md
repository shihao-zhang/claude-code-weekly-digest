## Claude Code 产品更新 (Claude Code Updates)

- **[v2.1.144 - /resume 后台会话支持 - 2026-05-19]** 新增 `/resume` 命令，支持直接恢复已分离的后台会话，无需手动从 Agent View 列表中选取，进一步打通前台与后台的任务切换流程。([GitHub Release v2.1.144](https://github.com/anthropics/claude-code/releases/tag/v2.1.144))

- **[v2.1.145 - claude agents --json & 插件预览 - 2026-05-19]** 两项面向开发者的效率功能同步上线：
  - **`claude agents --json`**：以 JSON 格式输出当前所有活跃会话列表，专为脚本自动化设计，可对接 tmux-resurrect、状态栏组件、自定义会话选择器等工具链。
  - **`/plugin` 发现页增强**：Browse/Discover 面板在安装前新增插件预览窗格，可直接查看技能列表、MCP 服务器描述及权限清单，降低"盲装"风险。
  ([GitHub Release v2.1.145](https://github.com/anthropics/claude-code/releases/tag/v2.1.145))

- **[v2.1.146 - /simplify 重命名为 /code-review - 2026-05-21]** 原 `/simplify` 命令正式更名为 `/code-review`，语义更准确，功能也随之增强：
  - 支持可选努力等级参数，如 `/code-review high`（高覆盖，可能包含不确定发现）、`/code-review medium`（默认）、`/code-review low`（仅高置信度 Bug）
  - 新增 `--comment` 标志，可将发现直接以内联评论形式推送至 GitHub PR，无需离开终端
  - 旧的 `/simplify` 命令在过渡期内保留别名，后续版本将移除
  ([GitHub Release v2.1.146](https://github.com/anthropics/claude-code/releases/tag/v2.1.146))

- **[v2.1.147 - 固定后台会话（Pinned Sessions）- 2026-05-21]** Agent View 新增会话固定能力：在 `claude agents` 界面中按 **Ctrl+T** 可将任意会话固定至列表顶部；固定会话在空闲时保持进程存活（非固定会话在内存压力下可被回收）；Claude Code 自动更新时，固定会话将在原位重启以应用最新版本，最大程度减少任务中断。**注意**：v2.1.147 引入了一个回归 Bug（Bash 工具对所有命令返回退出码 127），已在 v2.1.148 中修复。([GitHub Release v2.1.147](https://github.com/anthropics/claude-code/releases/tag/v2.1.147), [Agent View 文档](https://code.claude.com/docs/en/agent-view))

- **[v2.1.148 - 紧急热修复 - 2026-05-22]** 修复 v2.1.147 引入的关键回归：Bash 工具对所有命令一律返回退出码 127，导致几乎所有需要执行 Shell 命令的工作流中断。建议跳过 v2.1.147 直接升级至 v2.1.148 或更高版本。([GitHub Release v2.1.148](https://github.com/anthropics/claude-code/releases/tag/v2.1.148))

- **[v2.1.149 - /usage 成本分类 & Markdown 渲染改进 - 2026-05-22]** 本周功能最丰富的版本：
  - **`/usage` 分类成本明细**：使用量面板新增按类别拆分的限额消耗展示，可分别查看 Skills、Subagents、Plugins 及各 MCP 服务器的 Token 占用
  - **`/diff` 键盘可滚动**：Diff 详情视图现在支持键盘导航（方向键、j/k、PgUp/PgDn、Space、Home/End）
  - **GFM 任务清单渲染**：Markdown 输出现在正确渲染 `- [ ] 待办` / `- [x] 已完成` 样式的任务复选框
  - **企业新配置**：新增 `allowAllClaudeAiMcps` 托管设置项
  - **Bug 修复**：修复 PowerShell 权限绕过漏洞、git worktree 沙箱写入白名单、Bedrock/Vertex 用户无法从 `/model` 选择 "Opus (1M context)"、远程会话登录报错 "Can't access this organization" 等多项问题
  ([GitHub Release v2.1.149](https://github.com/anthropics/claude-code/releases/tag/v2.1.149), [claudeupdates.dev](https://www.claudeupdates.dev/version/2.1.149))

## Codex CLI 产品更新 (Codex CLI Updates)

- **[v0.131.0 - Python SDK 迁移 + codex doctor + 会话历史搜索 - 2026-05-20 前后]** 本周 Codex CLI 正式发布 v0.131.0，多项开发者体验改进同时落地：
  - **Python SDK 迁移**：Python SDK 正式更名为 `openai-codex` / `openai_codex`（PyPI 包名同步变更），引入 pinned runtime-generated types、并发轮次路由（concurrent turn routing）及 approval modes，与 Rust CLI 的功能深度对齐
  - **`codex doctor`**：新增专用诊断命令，覆盖 runtime、auth、terminal、network、config 和本地状态六大维度，一键生成支持友好的诊断报告，大幅降低环境排查成本
  - **本地会话历史搜索**：新增跨本地对话历史的全文搜索，支持大小写不敏感的内容匹配与结果预览，类似于 Shell 的 `Ctrl+R`，但针对完整的 Agent 对话历史
  - **第一方认证 API**：Python SDK 新增完整认证支持，覆盖 API key 登录、ChatGPT 浏览器流、设备码流（device-code flow）、账号检查与注销 API，为自动化脚本的授权管理提供规范入口
  ([X/@CodexReleases](https://x.com/CodexReleases/status/2056431344604025041), [Codex Changelog](https://developers.openai.com/codex/changelog), [GitHub Releases](https://github.com/openai/codex/releases))

## 实用技巧 (Tips & Tricks)

- **`/code-review` 三档努力等级按需选用（Claude Code）**：日常快速检查用 `/code-review low`（仅高置信度 Bug，速度最快）；PR 提交前用默认的 `/code-review`；安全敏感或架构重构时用 `/code-review high`。结合 `--comment` 标志可直接把发现推送为 GitHub inline 评论，无需复制粘贴。([GitHub Release v2.1.146](https://github.com/anthropics/claude-code/releases/tag/v2.1.146))

- **`claude agents --json` 接入状态栏与自动化（Claude Code）**：将 `claude agents --json` 嵌入 tmux 状态栏脚本或 shell 函数，可实时展示运行中会话数量；也可与 `jq` 搭配筛选"等待输入"会话并触发系统通知，无需一直盯着 Agent View。([GitHub Release v2.1.145](https://github.com/anthropics/claude-code/releases/tag/v2.1.145))

- **Ctrl+T 固定关键后台会话（Claude Code）**：对于跑时间长、不希望被内存回收的后台任务（如大型重构、测试全量覆盖），在 `claude agents` 中按 Ctrl+T 固定该行。固定后即使 Claude Code 自动更新，该会话也会原位重启，不会丢失任务进度。([GitHub Release v2.1.147](https://github.com/anthropics/claude-code/releases/tag/v2.1.147))

- **`codex doctor` 排查环境问题（Codex CLI）**：在提交 Bug 报告或调试环境问题前，先运行 `codex doctor`，它会输出一份覆盖 runtime/auth/terminal/network/config 六大维度的诊断摘要，省去手动排查的时间。([X/@CodexReleases](https://x.com/CodexReleases/status/2056431344604025041))

- **Gemini CLI 会话导出跨环境共享（Gemini CLI）**：v0.43.0 支持将活跃会话导出为文件，可在不同机器或不同终端实例间传递上下文，特别适合在本地开发环境与远程服务器之间迁移长期进行中的 Agent 任务。([Gemini CLI 最新版 Changelog](https://geminicli.com/docs/changelogs/latest/))

## 横向洞察 (Cross-cutting Insights)

**Gemini CLI 宣布向 Antigravity CLI 迁移是本周赛道最重要的结构性信号**。这意味着 Google 将彻底重构其 terminal AI coding 品牌——从一个以 Gemini 模型为中心的单一工具，演进为一个多模型、多智能体的 coding infrastructure 平台。"Antigravity" 这个名字本身就在暗示：不再受重力（模型 / 工具边界）的束缚。这与 Anthropic 把 Claude Code 定位为"Agentic 软件开发平台"而非仅仅是"AI 编程助手"的方向高度一致。各家厂商都在将工具从模型附属物中解放出来，向独立平台演进。

本周 Claude Code、Codex CLI、Gemini CLI 三大工具的功能更新有一个共同主题：**让开发者更清晰地看到 Agent 在消耗什么**。Claude Code v2.1.149 的 `/usage` 分类成本明细、Codex CLI v0.131.0 的 `codex doctor` 健康报告、Gemini CLI v0.43.0 的自适应 token 计算器——都是在同一方向上的独立行动：token 成本可观测性正在从"nice-to-have"变成"must-have"。随着 agentic workflow 的任务规模持续扩大，开发者需要能够看清 Agent 的花费去向。

**session persistence 是本周更新的另一主线**：Claude Code Pinned Sessions（Ctrl+T）、Codex CLI 的本地历史搜索和会话导出、Gemini CLI 的会话导出/导入——三大工具都在本周强化了"不丢失"的能力。AI Agent 任务越来越长，跨会话的上下文连续性正在从可选功能变成基础设施。
