## 实用技巧 (Tips & Tricks)

- **用 `/code-review` 后台审查不阻塞主对话（Claude Code v2.1.218）**：`/code-review` 现在作为后台子 Agent 运行，审查过程不再占用主对话空间。你可以触发审查后继续正常工作，审查结果会在后台完成后出现。特别适合大型 PR 的边工作边审查场景。([Official Changelog](https://code.claude.com/docs/en/changelog))

- **`sandbox.network.strictAllowlist` 实现零信任网络（Claude Code v2.1.219）**：设置后，沙盒命令只能访问白名单主机，非白名单请求直接拒绝无需逐次提示。适用于有严格网络合规要求的企业环境。([Official Changelog](https://code.claude.com/docs/en/changelog))

- **Codex `/import` 一键迁移 Claude Code 配置（Codex v0.145.0）**：如果你同时使用 Claude Code 和 Codex，现在 `/import` 命令可以直接迁移 MCP 服务器、插件、会话、命令和项目级 memories 到 Codex——不再需要手动重配。([GitHub Release v0.145.0](https://github.com/openai/codex/releases/tag/rust-v0.145.0))

- **用 ChatGPT Voice 语音指挥 Codex Agent（2026-07-24）**：在 ChatGPT 桌面应用中启用 GPT-Live 语音后，可以口头指挥多个并行运行的 Codex Agent——适合同时跑多个独立任务时不想切换窗口打字。([9to5Mac](https://9to5mac.com/2026/07/23/openai-updating-chatgpt-desktop-app-with-gpt-voice-for-talking-through-work/))

- **嵌套子 Agent 实现复杂分解（Claude Code v2.1.218）**：子 Agent 现在可以再生成子 Agent（最大深度 3 层），适合"架构设计→模块拆分→具体实现"这类递归分解场景。如果不需要此行为，`CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH=1` 恢复旧限制。([Official Changelog](https://code.claude.com/docs/en/changelog))

## 横向洞察 (Cross-cutting Insights)

**Claude Opus 5 的发布是本周的枢纽事件——它将所有主要平台的模型底座同步拉升到新高度。** Anthropic 以 Opus 4.8 同价推出 1M 上下文、128K 输出的 Opus 5，24 小时内 Claude Code（v2.1.219）、Kiro（v2.14.0）、GitHub Copilot 同步上线。这不是一个工具的更新，而是整个生态层的地基升级。更值得注意的是 Codex v0.145.0 同周稳定的 Multi-Agent V2 和 Amazon Bedrock 支持——OpenAI 正在将 Agent 编排从"实验性功能"推向生产基础设施。当两大平台同时将"多 Agent 协作"和"超长上下文"作为稳定功能交付时，说明 AI 编程工具的竞争已经从"模型能力"转向"编排层成熟度"。

**"自主性边界"正在被重新划定——不是收紧，而是精细化。** 本周的信号高度一致：Claude Code 的 `sandbox.network.strictAllowlist` 和 `sandbox.filesystem.disabled` 让安全控制从"全有/全无"变为维度级开关；Codex v0.145.0 的分支对话（branching conversations）让用户可以安全地"假设探索"而不污染主线；Amp 的自调度 Agent 是自主性的极端扩展——Agent 自己设定时间表并持续工作。GhostApproval 漏洞（3/6 工具仍未修补）则是对过度信任的警告。这些看似矛盾的方向实际上是同一趋势的两面：工具正在从"单一安全模式"演化为"可调谐的自主性频谱"——开发者不再选择"安全或快速"，而是为每个场景精确设定 Agent 可以做什么。

**互操作性正在从愿景变为竞争武器。** Codex `/import` 现在直接吸收 Claude Code 和 Cursor 的配置；MCP 2026-07-28 的无状态化让服务器可以被任何客户端无差别调用；Antigravity CLI 通过 Markdown 文件定义自定义 Agent 降低了生态进入门槛。"两 Agent 工作流"成为主流（65% 工程师日常使用两个 Agent）不是偶然——它反映了单一工具无法覆盖开发全链路的现实。本周的关键信号是：赢家不再是"最好的单一工具"，而是"最容易被组合进工作流的工具"。Codex 的 `/import` 本质是在说："你不需要放弃 Claude Code 才能用我"——这比功能竞争更有杀伤力。
