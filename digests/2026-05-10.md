## 实用技巧 (Tips & Tricks)

- **Ollama 本地模型替代云端**：设置 `ANTHROPIC_BASE_URL=http://localhost:11434` 与 `ANTHROPIC_AUTH_TOKEN=ollama`，即可将 Claude Code 的后端切换为本地 Ollama 模型（如 Qwen3.6:27b，SWE-Bench Verified 得分 77.2%）。适合需要离线工作或控制 API 成本的场景，建议使用 16GB+ VRAM GPU 或 Apple M 系列 Mac（32GB+ 内存）。([DataCamp 教程](https://www.datacamp.com/tutorial/using-claude-code-with-ollama-local-models), [Ollama 官方集成文档](https://docs.ollama.com/integrations/claude-code))

- **`CLAUDE_CODE_DISABLE_ALTERNATE_SCREEN=1`**：若你的终端（如某些 SSH 会话、tmux 面板或无全屏模式的环境）不适合 Claude Code 的全屏替代渲染模式，设置此变量可回归终端原生滚动缓冲区，更便于复制输出历史。(v2.1.129 新增)

- **`--plugin-url` 测试远程插件**：开发或分享 Claude Code 插件时，可以直接把打包好的 `.zip` 发布到任意 URL，接收方无需本地安装，直接在启动命令中加上 `--plugin-url <url>` 即可本次会话体验，大幅降低插件试用门槛。(v2.1.129 新增)

- **`settings.autoMode.hard_deny` 强化安全策略**：在企业或 CI 环境中，可用此配置项设置无条件拒绝规则，防止 Auto 模式在高风险操作上被用户意图或上下文"说服"绕过，比仅用 `deny` 更严格。(v2.1.136 新增)

- **`CLAUDE_CODE_SESSION_ID` 追踪子进程来源**：Bash 工具子进程现在自动获得 `CLAUDE_CODE_SESSION_ID` 环境变量，便于在脚本或日志中标识触发来源 Session，方便多 Session 并发时的审计与调试。(v2.1.129 新增)
