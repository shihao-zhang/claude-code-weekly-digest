## Codex CLI 产品更新 (Codex CLI Updates)

- **[v0.129.0 - 2026-05-07]** 功能密集的大版本（注：部分来源标注为 4 月 29 日，本周生效）：
  - **`/vim` 模态编辑器**：在 Composer 内引入 Vim 模态编辑，支持 normal/insert/off 三种配置，是 OpenAI 首次为 Vim 用户提供第一方支持
  - **`/hooks` 可视化管理浏览器**：全新钩子管理界面，支持工作区范围共享、访问控制、来源筛选、本地路径追踪及 pre/post-compaction 钩子
  - **会话恢复/分叉选择器重设计**：新增原始滚动回看（raw scrollback）模式和工作区感知 `/diff` 视图
  - **主题感知状态栏**：状态栏颜色随终端主题变化，支持在提示区显示 PR 摘要和当前分支信息
  ([GitHub Releases](https://github.com/openai/codex/releases), [Codex Changelog](https://developers.openai.com/codex/changelog))

- **[v0.130.0 - 2026-05-08]** 安全与体验改进：
  - **钩子内置信任审查流**：新增应用内 trust review 工作流，在首次执行钩子前引导用户显式审查权限，即使钩子尚未完全配置也可进入 Hooks 设置
  - **桌面工作流修复**：恢复 tooltip-wrapped 下拉菜单；保留线程切换时的消息编辑进度；修复 Windows 终端粘贴、外部链接跳转及反馈命令与错误线程绑定等多项回归
  - **加载体验优化**：线程恢复时显示模型加载状态，加载期间隐藏不可用的模型控件
  ([GitHub Release v0.130.0](https://github.com/openai/codex/releases/tag/rust-v0.130.0), [Releasebot](https://releasebot.io/updates/openai/codex))

## 实用技巧 (Tips & Tricks)

- **`CLAUDE_CODE_DISABLE_ALTERNATE_SCREEN=1` 回归原生滚动（Claude Code）**：若你的终端（如某些 SSH 会话、tmux 面板）不适合全屏替代渲染模式，设置此变量可回归终端原生滚动缓冲区，更便于复制输出历史。(v2.1.129 新增)

- **`--plugin-url` 测试远程插件（Claude Code）**：开发或分享 Claude Code 插件时，可以直接把打包好的 `.zip` 发布到任意 URL，接收方无需本地安装，直接在启动命令中加 `--plugin-url <url>` 即可本次会话体验，大幅降低插件试用门槛。(v2.1.129 新增)

- **`settings.autoMode.hard_deny` 强化安全策略（Claude Code）**：在企业或 CI 环境中，用此配置项设置无条件拒绝规则，防止 Auto 模式在高风险操作上被用户意图"说服"绕过，比仅用 `deny` 更严格。(v2.1.136 新增)

- **Codex CLI `/hooks` 可视化管理（Codex CLI）**：v0.129.0 的 `/hooks` 界面支持可视化管理所有注册的钩子，设置工作区范围的共享访问控制，无需手动编辑配置文件，降低多人协作时的钩子冲突风险。([GitHub Releases](https://github.com/openai/codex/releases))

- **Gemini CLI 语音交互（Gemini CLI）**：v0.41.0 新增实时语音模式，可用自然语言口述编码需求，适合双手被占用或需要快速描述想法的场景，支持切换云端/本地语音后端。([Gemini CLI Changelog](https://geminicli.com/docs/changelogs/))
