## 实用技巧 (Tips & Tricks)

- **`ultracode` 关键词触发动态工作流（Claude Code）**：在任意 prompt 中加入 `ultracode` 关键词，Claude Code 即自动切换为 Dynamic Workflow 模式，生成编排脚本并启动多 Agent 并行任务，无需手动设置 `/effort`。对于单次大任务使用关键词触发；对于整个会话，运行 `/effort ultracode` 设为持久默认。([claude.com 博客](https://claude.com/blog/introducing-dynamic-workflows-in-claude-code))

- **`claude agents --json | jq '.[] | select(.waitingFor != null)'` 找出卡住的 Agent（Claude Code）**：v2.1.162 的 `waitingFor` 字段让 `claude agents --json` 变得更实用——通过 jq 过滤出所有非 null `waitingFor` 的会话，即可快速定位哪些后台 Agent 在等待用户确认或工具返回，无需逐一查看。([GitHub Release v2.1.162](https://github.com/anthropics/claude-code/releases/tag/v2.1.162))

- **`/plugin list --enabled` 审计已激活插件（Claude Code）**：在多插件环境或企业部署中，`/plugin list --enabled` 可快速列出所有当前激活的插件，`--disabled` 反向查看未激活的。配合 v2.1.163 的 `requiredMinimumVersion` 使用，构建插件状态的完整审计链。([GitHub Release v2.1.163](https://github.com/anthropics/claude-code/releases/tag/v2.1.163))

- **`codex archive` 冻结调试上下文（Codex CLI）**：在 Codex CLI v0.137.0 中，用 `codex archive` 归档当前会话可将其"冻结"——不可 resume 或 fork，直到手动 `codex unarchive` 还原。适合保存重要的历史调试状态，防止误操作覆盖。([Codex Changelog](https://developers.openai.com/codex/changelog))

- **CI/CD 安全：降低 Claude Code Action 权限（通用建议）**：在 GitHub Actions workflow 中使用 Claude Code Action 时，将 `permissions` 块收窄至最小必要权限（如仅 `pull-requests: write`，而非 `contents: write`），并在 `env` 中显式不挂载非必要 secrets。v1.0.94 已从子进程中清除环境变量，但最小权限原则依然是 agentic CI 的第一防线。([Microsoft Security Blog](https://www.microsoft.com/en-us/security/blog/2026/06/05/securing-ci-cd-in-agentic-world-claude-code-github-action-case/))

## 横向洞察 (Cross-cutting Insights)

**本周最大的结构性信号不是某项功能更新，而是 ACP（Agent Client Protocol）的生态化**。Windsurf 更名为 Devin Desktop 的核心意义在于：ACP 这套开源协议已被 Devin Desktop、JetBrains、Google、GitHub 及 25+ 个 Agent 采纳，Claude Code 自己也在 v2.1.162 中将菜单项更新为"Devin Desktop"——这意味着 AI coding agent 生态正在悄然建立第一套真正的互操作标准。历史上，IDE 和语言服务器通过 LSP 完成了工具链的统一；ACP 在试图对 AI Agent 完成同样的事情。这比任何单一功能更新都更值得关注。

**安全成为 agentic CI/CD 的头号议题**。GMO Flatt Security 的研究和 Microsoft 的独立披露共同揭示了一个结构性问题：AI Agent 在 CI/CD 环境中天然拥有 runner 的完整权限，而 prompt injection 攻击面（Issue 正文、PR 评论、README）远比传统 CI/CD 风险面更宽。这不是 Anthropic 独有的问题——SecurityWeek 的报道同时点名了 Gemini CLI 和 GitHub Copilot Agents。agentic 工具链的普及速度已经超过了安全最佳实践的沉淀速度，这个差距在未来半年内将是整个赛道最重要的非功能性挑战。

**Dynamic Workflows（Claude Code）与 Multi-agent v2（Codex CLI）的同步成熟，标志着"编排器+子 Agent 群"成为两大 Tier 1 工具的共识架构**。Anthropic 内测数据显示启用 Dynamic Workflows 后任务完成率显著提升（Harvey 案例约 6 倍），而 Codex CLI v0.137.0 的 Multi-agent v2 也在独立推进类似的运行时路由能力。赛道竞争的焦点正在从"谁的模型更聪明"转向"谁的 Agent 编排更稳定、可观测、可审计"——fallbackModel、waitingFor、OTEL 标签、/usage 成本分类这些本周新增的特性，背后都指向同一个命题：让 Agent 的行为可测量、可解释、可控。
