## Claude Code 产品更新 (Claude Code Updates)

- **[v2.1.186 - `claude mcp login/logout` CLI 认证 + `respondToBashCommands` 默认行为变更 - 2026-06-23]** 本周功能面最重要的版本：
  - **`claude mcp login <name>` / `claude mcp logout <name>`**：新增从 CLI 直接认证 MCP 服务器的能力，无需进入交互式 `/mcp` 菜单。支持 `--no-browser` stdin 重定向，可在 SSH 会话中完成认证
  - **`respondToBashCommands` 行为变更**：`!` 前缀执行的 Bash 命令现在默认触发 Claude 对输出进行自动响应；可在 settings.json 中设置 `"respondToBashCommands": false` 恢复此前仅注入上下文的行为
  - 新增 `/plugin` Installed 标签页的 "Skills" 分区；支持 iTerm2 作为 teammate 显示目标（自动检测 it2 CLI）
  - `/workflows` Agent 详情视图新增状态筛选（按 `f` 键）
  - 修复 Chrome 标签页组隔离在产品内权限开关关闭时未生效的问题；MEMORY.md 索引接近大小上限时自动提示 agent 进行压缩

  ([Claude Code Changelog](https://code.claude.com/docs/en/changelog), [DevelopersIO v2.1.184–v2.1.186 解析](https://dev.classmethod.jp/en/articles/20260623-cc-updates-v2-1-186/))

- **[v2.1.187 - 组织级模型限制 + `sandbox.credentials` 凭据隔离 - 2026-06-23]** 安全与企业治理向的重要更新：
  - **组织级模型限制全面生效**：管理员配置的模型白名单现在同时反映在 model picker、`--model`、`/model` 和 `ANTHROPIC_MODEL` 环境变量中，消除了此前部分入口可绕过限制的缺口
  - **`sandbox.credentials` 设置**：新增沙箱级凭据隔离——开启后，沙箱内运行的命令无法读取凭据文件和 secret 环境变量，防止恶意或意外的工具调用泄露敏感信息
  - 权限提示和选择菜单（如 `/model`、`/config`）现在支持全屏模式下的鼠标点击选择

  ([Claude Code Changelog](https://code.claude.com/docs/en/changelog), [DevelopersIO v2.1.187–v2.1.191 解析](https://dev.classmethod.jp/en/articles/20260625-cc-updates-v2-1-191/), [GitHub Issue #70440](https://github.com/anthropics/claude-code/issues/70440))

- **[v2.1.191 - `/rewind` 跨 `/clear` 回溯 + 流式 CPU 占用降低 37% - 2026-06-25]** 本周最受社区关注的版本：
  - **`/rewind` 增强**：现在可以回溯到 `/clear` 之前的状态恢复会话上下文，解决了此前 `/clear` 后无法回到之前对话状态的痛点
  - **流式传输 CPU 占用降低约 37%**：通过 100ms 文本更新合并（coalescing），大幅减少流式响应期间的 CPU 开销
  - **MCP 可靠性提升**：能力发现（tools/list、prompts/list、resources/list）在临时网络错误时自动重试并短暂退避；MCP OAuth 发现和令牌请求在网络错误后重试一次，headless 环境中跳过浏览器弹窗改为 URL 粘贴提示
  - 修复流式响应期间阅读早期输出时滚动位置跳到底部的问题；修复已停止的后台 Agent 意外重启的 bug；多工具匹配器的 Hooks（如 `"Bash,PowerShell"`）现在能正确解析（此前静默失效）
  - `/voice` 在 Linux 上区分"无麦克风"和"未安装 SoX"两种错误；`claude agents completed` 列表改为自适应填充可用垂直空间

  ([Claude Code Changelog](https://code.claude.com/docs/en/changelog), [DevelopersIO 解析](https://dev.classmethod.jp/en/articles/20260625-cc-updates-v2-1-191/), [explainx.ai v2.1.191 详解](https://www.explainx.ai/blog/claude-code-2-1-191-rewind-mcp-background-agents-2026))

## Codex CLI 产品更新 (Codex CLI Updates)

- **[v0.142.0 - Remote GA + Token Budget + 索引式 Web 搜索 + 多 Agent 委托配置 - 2026-06-22]** 功能覆盖面极广的版本，Codex Remote 正式进入 General Availability：
  - **Remote GA**：用户可从 ChatGPT 移动端 App 在已连接的 Mac/Windows 主机上启动或继续工作，审核进度并批准操作。Remote Control 改为**经过身份验证的一对一 QR 配对**（每台 iOS/Android 设备与每台主机之间），6 月 8 日之后使用的连接保持配对，更早的需重新配对
  - **DigitalOcean 远程工作区插件**：新插件可直接从 Codex 内创建 DigitalOcean Droplet、配置 SSH 访问并连接为远程工作区
  - **可配置 Rollout Token Budget**：在 agent 线程级跟踪 token 使用量，提供剩余预算提醒，预算耗尽时自动中止 turn
  - **索引式 Web 搜索模式**：允许实时搜索但限制直接页面访问仅限服务器批准的 URL，在安全性与实用性之间取得平衡
  - **多 Agent 委托配置**：App-server 客户端可在 thread 和 turn 级别配置多 Agent 委托为禁用、仅显式请求或主动模式
  - **时间功能**：Codex 可接收计划的 UTC 时间提醒并直接查询当前时间（含通过 app-server 时钟）
  - `/usage` 现在可显示和兑换已获得的用量限制重置积分；`/plugins` 按 OpenAI Curated / Workspace / Shared with me 分类组织远程插件

## 社区热点 (Community Highlights)

- **[Agentjacking：通过伪造 Sentry 错误报告劫持 AI Coding Agent — 85% 成功率]** Tenet Security 于本周公开披露了名为 "Agentjacking" 的新型攻击类别：攻击者找到目标的 Sentry DSN（公开的写入凭证，嵌入在前端 JavaScript 中），向 Sentry 注入包含恶意指令的伪造错误事件。AI coding agent（Claude Code、Cursor、Codex 均受影响）将这些指令视为合法的调试指导并执行，实质上是间接 prompt injection 攻击。研究者实现了 **85% 的成功率**，发现至少 **2,388 个组织**暴露了可注入的 DSN。该攻击无需钓鱼、绕过 EDR/防火墙/IAM/VPN，因整个链条中没有任何未授权操作。

  ([The Hacker News](https://thehackernews.com/2026/06/agentjacking-attack-tricks-ai-coding.html), [The New Stack 深度分析](https://thenewstack.io/agentjacking-sentry-mcp-attack/), [Tenet Security 原始研究](https://tenetsecurity.ai/blog/agentjacking-coding-agents-with-fake-sentry-errors/))

- **[GitHub Copilot for JetBrains：Claude 首次作为第三方 Agent Provider 入驻 IDE 插件生态]** Claude Code 作为 agent provider 在 JetBrains IDE 的 GitHub Copilot 中进入 public preview，这是 Claude Code 首次以"可选 agent"身份进入非 Anthropic 自有的 IDE 插件生态。社区讨论集中在 bypass permissions 模式的安全隐患——当前所有文件编辑和工具调用均自动批准，缺少 Claude Code CLI 原生的权限管控层。JetBrains YouTrack 上已有多个相关 issue（如要求支持 Claude Code OAuth 凭证、尊重 AGENTS.md 设定等）。

  ([GitHub Blog Changelog](https://github.blog/changelog/2026-06-22-new-features-and-claude-as-agent-provider-preview-in-jetbrains-ides/), [JetBrains YouTrack LLM-24706](https://youtrack.jetbrains.com/projects/LLM/issues/LLM-24706/Add-Support-for-Claude-Code-OAuth-credentials-in-the-Claude-Agent))

- **[社区情绪：验证能力而非生成能力成为瓶颈]** Hacker News 和 Reddit 本周的高票讨论反映了一个清晰的趋势转变：开发者争论的焦点不再是"这些工具是否真的有用"，而是"如何让它们在经济上可行、运营上可信、结构上可重复"。r/ClaudeAI 上"Claude Code 是最好的 coding agent"获 270 upvotes；r/codex 上"有了正确的 skills，Codex 比 Claude Code 更好用"获 468 upvotes——两个社区各自认为自己的工具更优，但核心议题已趋同：**2026 年的瓶颈不再是代码生成速度，而是验证能力**。

## 实用技巧 (Tips & Tricks)

- **`claude mcp login` 在 SSH 远程开发中认证 MCP 服务器（Claude Code）**：v2.1.186 起，使用 `claude mcp login <name> --no-browser` 可在无图形界面的 SSH 会话中完成 MCP 服务器 OAuth 认证——终端输出 URL，在本地浏览器中完成认证后粘贴令牌即可。这解决了远程开发环境中 MCP OAuth 认证的长期痛点。([Claude Code Changelog](https://code.claude.com/docs/en/changelog))

- **`sandbox.credentials` 防止沙箱泄露凭据（Claude Code）**：v2.1.187 新增的设置，开启后沙箱内运行的 Bash 命令无法读取 `.env`、AWS credentials 等凭据文件和 secret 环境变量。对于在 auto mode 下大量使用第三方 MCP 工具的用户，这一层隔离可有效防止工具意外或恶意读取敏感凭据。([Claude Code Changelog](https://code.claude.com/docs/en/changelog), [GitHub Issue #70440](https://github.com/anthropics/claude-code/issues/70440))

- **Token Budget 精确管控 agent 开销（Codex CLI）**：v0.142.0 的可配置 Rollout Token Budget 允许在 agent 线程级设定 token 使用上限，超出时自动中止 turn 并提供剩余预算提醒。对于成本敏感的团队或自动化流水线，这比事后查看 `/usage` 更具控制力。([Codex Changelog](https://developers.openai.com/codex/changelog))

- **`/rewind` 恢复 `/clear` 前的上下文（Claude Code）**：v2.1.191 起，`/clear` 不再是不可逆操作。执行 `/rewind` 即可回溯到 `/clear` 之前的会话状态，恢复完整上下文继续工作。适用于误执行 `/clear` 或需要在"清空后的干净视角"和"完整历史上下文"之间切换的场景。([Claude Code Changelog](https://code.claude.com/docs/en/changelog))

## 横向洞察 (Cross-cutting Insights)

**本周最大的系统性主题是"AI coding agent 的信任边界在攻防两端同时重新划定"**。Agentjacking 攻击以 85% 成功率劫持 Claude Code / Cursor / Codex，Amazon Q Developer 的 MCP 自动执行漏洞可从 git clone 直达云端沦陷——这两起事件在同一周集中爆出，暴露了当前 AI coding agent 安全架构的结构性弱点：agent 无法区分来自可信工具（Sentry、MCP 服务器）的合法指令和注入的恶意指令。与此同时，Claude Code 在 v2.1.187 引入 `sandbox.credentials` 凭据隔离、上周 v2.1.183 的 auto mode 安全守卫，以及 Amazon Q 修复 MCP 漏洞，都表明厂商正在加速构建防御层。但问题是：**当前的防御是"事后补洞"式的，而攻击面正在随着工具链集成度的提升而指数级扩大**。Sentry DSN 是一个完全合法的公开凭证，MCP 配置文件是工具链的标准组件——攻击者正在利用的恰恰是工具链自身的"正常功能"。

**GPT-5.6 Sol 以限定预览方式发布，标志着前沿模型分发正式进入"政府管控"时代**。这是首次有美国 AI 公司在政府逐一审批的合作伙伴列表下发布前沿模型。从 AI coding agent 赛道的视角看，这意味着 Codex CLI 用户最早可能在数周后才能使用 Sol——但 Terminal-Bench 2.1 上 91.9%（Ultra 模式）的成绩已经改变了竞争格局的预期。值得注意的是，Terminal-Bench 衡量的是 CLI 工作流，而 FrontierCode 衡量的是 PR 可合并性；两个基准测试的分歧（Terminal-Bench 上模型分数普遍 80%+，FrontierCode Diamond 上最高仅 13.4%）揭示了一个关键鸿沟：**当前模型在"完成任务"上已接近天花板，但在"生成可合并的生产级代码"上仍处于早期阶段**。

**Codex Remote GA 与 Claude Code JetBrains Preview 从不同方向解决同一个问题：扩展 agent 的可达性**。Codex 选择移动端→桌面主机的远程控制路径（QR 配对、手机审批），Claude Code 选择嵌入第三方 IDE 插件生态（JetBrains + GitHub Copilot）。两者的共同信号是：CLI-first 的 AI coding agent 已不满足于"只在终端中运行"，正在向 IDE、移动端、远程工作区全面扩张。区别在于 Codex 的扩张保持了对自有生态的控制（ChatGPT App 为入口），而 Claude Code 的 JetBrains 集成以 bypass permissions 模式运行，实质上让渡了安全管控——这在生产环境中可能成为采用障碍。
