## 实用技巧 (Tips & Tricks)

- **CLAUDE.md + AGENTS.md 双文件策略**：把实际内容写在 `AGENTS.md`（多 Agent 平台可移植），在 `CLAUDE.md` 中用 `@AGENTS.md` 引用，兼顾跨工具兼容性。([CCBP](https://github.com/shanraisshan/claude-code-best-practice))

- **Hook 比 CLAUDE.md 更可靠**：CLAUDE.md 属于"建议"（约 80% 遵从率），Hook 是"确定"（100% 执行）。必须每次执行的事（格式化、lint、测试）应写成 Hook，而非仅放在 CLAUDE.md。([Claude Code Best Practices](https://code.claude.com/docs/en/best-practices))

- **控制 CLAUDE.md 长度**：建议保持在 200 行以内，过长会消耗 token 并降低 Claude 的实际关注度。

- **非 trivial 任务先用 Plan 模式**：告诉 Claude 先思考、列计划，等你确认后再执行，可以大幅减少返工。

- **用 git worktree 并行运行多个 Claude Code 会话**：在不同 worktree 中同时处理多个功能分支，互不干扰。([ykdojo/claude-code-tips](https://github.com/ykdojo/claude-code-tips))

- **用 Gemini CLI 作为 Claude Code 的"小弟"**：将 Gemini CLI 集成进工作流，用于处理大规模代码库索引、海量文件搜索等 token 密集型任务，节省主会话 token。([ykdojo/claude-code-tips](https://github.com/ykdojo/claude-code-tips))
