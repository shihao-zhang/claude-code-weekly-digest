## Claude Code 产品更新 (Claude Code Updates)

- **[v2.1.197 - Claude Sonnet 5 成为默认模型 - 2026-06-30]** 本周最重大的变更：Claude Sonnet 5 正式成为 Claude Code 的默认模型，面向 Free 和 Pro 用户。原生支持 1M token 上下文窗口和 128K max output tokens。推广期定价 $2/$10 per Mtok（持续至 8 月 31 日）。注意行为变更：Adaptive thinking 默认开启，手动设置 extended thinking 或将 sampling 参数设为非默认值会返回 400 错误。新 tokenizer 对相同文本产生约 30% 更多 token。

  ([GitHub Release v2.1.197](https://github.com/anthropics/claude-code/releases/tag/v2.1.197), [Anthropic 官方公告](https://www.anthropic.com/news/claude-sonnet-5), [Simon Willison 解析](https://simonwillison.net/2026/Jun/30/claude-sonnet-5/))

- **[v2.1.198 - 子 Agent 后台运行 GA + Chrome GA + 后台 Agent 自动创建 Draft PR - 2026-07-01]** 功能密度极高的版本：
  - **子 Agent 后台运行正式 GA**：Claude 在子 Agent 运行时继续工作，完成后收到通知——此前为灰度发布，现在全量生效
  - **Claude in Chrome 正式 GA**：浏览器内 Claude Code 集成离开 Beta
  - **后台 Agent 自动创建 Draft PR**：从 `claude agents` 启动的 Agent 在 worktree 中完成代码工作后，自动 commit、push 并创建 Draft PR，无需停下来询问用户
  - **后台 Agent 通知 Hook**：Agent 需要输入或完成时触发 `Notification` hook（`agent_needs_input` / `agent_completed`）
  - **新增 `/dataviz` 技能**：内置图表和仪表盘设计指导，含可运行的调色板验证器
  - **Explore Agent 升级**：继承主会话模型（上限 Opus），不再使用 Haiku
  - **Gateway 新增 Claude Platform on AWS 上游**：model-not-found 响应现在推进 failover 链
  - 移除 `/agents` 向导，改为通过 Claude 或 `.claude/agents/` 直接管理

  ([GitHub Release v2.1.198](https://github.com/anthropics/claude-code/releases/tag/v2.1.198), [DevelopersIO v2.1.197–v2.1.198 解析](https://dev.classmethod.jp/en/articles/20260702-cc-updates-v2-1-198/))

- **[v2.1.196 - 组织默认模型 + 后台会话可靠性大幅提升 - 2026-06-29]** 稳定性与企业治理向的重要版本：
  - **组织默认模型**：管理员可在 org console 设置默认模型，`/model` 中显示为 "Org default"（或 "Role default"）
  - **后台会话可靠性**：长时间运行的命令/工作流现在在进程停止、重启或更新后仍能存活（包括 Windows 的进程交接）；被 daemon 重启杀掉的后台 Agent 在下次打开 agents view 时自动恢复
  - **`/code-review` 优化**：合并 5 个清理查找器为 1 个，token 消耗降低约 25%
  - **流式看门狗默认启用**：所有 provider 在 5 分钟无事件后自动中止并重试
  - **安全修复**：`claude mcp list/get` 不再从通过已提交 `.claude/settings.json` 自批准的仓库中生成 `.mcp.json` 服务器
  - 大量后台 Agent 和 PowerShell 相关的 bug 修复（详见 Release Notes）

  ([GitHub Release v2.1.196](https://github.com/anthropics/claude-code/releases/tag/v2.1.196), [DevelopersIO v2.1.194–v2.1.196 解析](https://dev.classmethod.jp/en/articles/20260630-cc-updates-v2-1-196/))

## 实用技巧 (Tips & Tricks)

- **堆叠式 Slash-Skill 一次加载多个技能（Claude Code）**：v2.1.199 起，输入 `/skill-a /skill-b do XYZ` 可同时加载最多 5 个技能。例如 `/code-review /security-review audit this module` 会同时加载代码审查和安全审查技能后执行任务，无需分两次调用。([GitHub Release v2.1.199](https://github.com/anthropics/claude-code/releases/tag/v2.1.199))

- **后台 Agent 自动创建 PR 的工作流（Claude Code）**：v2.1.198 起，从 `claude agents` 在 worktree 中启动的 Agent 完成后会自动 commit、push 并创建 Draft PR。结合 `Notification` hook（`agent_needs_input` / `agent_completed`），可构建"启动→挂机→收到通知→审查 PR"的全自动工作流。([GitHub Release v2.1.198](https://github.com/anthropics/claude-code/releases/tag/v2.1.198))

- **"Caveman" 技能降低 Claude Code 输出 token 65%**：社区流行的 Julius Brussee "Caveman" skill 通过去除叙述/填充内容同时保留技术信息，平均减少 65% 的输出 token。对成本敏感的用户可将其添加到 `.claude/skills/` 目录中。([Firecrawl Best Skills](https://www.firecrawl.dev/blog/best-claude-code-skills))

- **Safari MCP 服务器调试前端（Claude Code / Codex）**：Apple 的 Safari MCP 服务器提供 16 个工具，coding agent 可直接检查网页 DOM、读取控制台日志、捕获截图。对于前端开发者，这消除了手动截图→粘贴→描述的循环，agent 可直接"看到"页面状态。([WebKit Blog](https://webkit.org/blog/18136/introducing-the-safari-mcp-server-for-web-developers/))

## 横向洞察 (Cross-cutting Insights)

**本周的标志性事件是 Claude Sonnet 5 发布和 Fable 5 恢复同步发生，重新定义了 AI coding agent 的模型供给格局**。Sonnet 5 以 $2/$10 per Mtok 的推广价成为 Claude Code 默认模型——这意味着 Claude Code 用户的"基础体验"现在建立在一个接近 Opus 4.8 能力但成本显著更低的模型上。与此同时，Fable 5 在 19 天出口管制后恢复全球可用，付费用户可在 7 月 7 日前免费使用 50% 额度。Anthropic 在一周内同时提供了"更便宜的日常模型"和"更强的旗舰模型"——这种"双轨策略"与 OpenAI 的 Sol/Terra/Luna 三层定价形成了有趣的镜像。但 GPT-5.6 Sol 仍未 GA（仅约 20 个组织可用），而 Sonnet 5 和 Fable 5 已面向所有用户开放——**模型可用性，而非模型能力，正在成为 2026 年 7 月的竞争关键变量**。

**安全叙事从"单点漏洞披露"升级为"系统性攻击面暴露"**。上周是 Agentjacking（通过 Sentry 假错误报告劫持 agent，85% 成功率）和 Amazon Q MCP 漏洞，本周是 GuardFall（11 款开源 agent 中 10 款的 shell 注入防护可被绕过）。两周内披露的攻击覆盖了三个完全不同的攻击面：外部数据注入（Sentry）、配置文件自动执行（MCP .json）、和命令解析差异（bash 重写 vs 纯文本检查）。共同模式是：**攻击者利用的不是工具链的"漏洞"，而是工具链的"正常功能"**——Sentry DSN 本就是公开的写入凭证，MCP 配置文件本就是标准组件，bash 的引号去除本就是语言规范。这使得传统的"打补丁"策略难以根除问题。Claude Code v2.1.196 的 MCP 安全修复和 v2.1.200 的权限模式重命名（"Default"→"Manual"，暗示默认应是手动审批）反映了厂商对此的回应方向：**让"安全"成为显式的、可感知的默认状态**。

**Cursor iOS Beta、Windsurf Cascade EOL、Claude in Chrome GA 三个事件共同指向一个趋势：AI coding agent 正在从"终端工具"演变为"全平台计算环境"**。Cursor 让用户从手机审查 PR 和启动 Agent；Windsurf 用 Devin Local（Rust 重写、ACP 协议）替换 Cascade，允许 Codex/Claude/OpenCode 作为一等 Agent 运行；Claude in Chrome 让浏览器成为 Claude Code 的入口；Apple Safari MCP 服务器让 coding agent 直接"看到"网页。65% 的工程师现在每天使用两个 AI coding agent——最常见的组合是 Cursor（编辑）+ Claude Code（交付）。这种多工具并用模式正在倒逼每个工具从"独占用户"转向"成为生态节点"的定位。
